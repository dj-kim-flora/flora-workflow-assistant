# Batch of variations

**Makes:** 10 to 50 versions of one idea: ads in different scenes, a product in different rooms, a logo in different materials.
**Start with:** one real image (the thing that must stay exact) and the idea in a sentence.
**Shape:** explore. One list box, one Batch, one generator (ladder: "One for each").

## Blocks
1. **THE THING:** the real image, labelled "your product (exact, do not redraw)".
2. **THE LIST:** one text box. Either typed by the person (no model) or written by the canvas: *"20 short prompts, bulleted, one line each, no preamble. each puts the product in a different scene. product copied exactly, nothing redrawn."* One short line per variation.
3. **BATCH:** the list into a Batch. The Batch into one consumer only.
4. **THE PICTURES:** one image box, the real image wired in, the text edge from the Batch.

## Empty slots
The real image. The idea. How many versions.

## Watch out
- Read the Batch's item count. If it says 1, the list did not split. Offer the Branches route instead.
- Run a Batch with the batch-run tool, never a normal generate: a normal generate runs the first item only and bills it.
- A Batch into two boxes that depend on each other multiplies runs (N times N) and cannot be cancelled.
- A typed list should have no model on its box, or it bills to repeat your own words.
- Specific beats vague: "hand-laid red brick, flush pointing" beats "brick".

## Cost note
Items times the per-run price. Run 3 first. Re-run only the winners at full quality.
