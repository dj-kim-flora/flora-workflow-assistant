# Restyle with a reference

**Makes:** one picture, or a whole folder, redrawn or retouched to look like a reference: a house illustration style, a mood, a material.
**Start with:** the real picture(s) and one reference of the same kind (a drawing for a drawing, a photo for a photo).
**Shape:** execute. Image + Image > Image, or the look written as words when a reference cannot sit beside every picture.

## Blocks
1. **YOUR PICTURE:** real file.
2. **THE LOOK:** the reference, labelled "reference (same kind of picture as yours)".
3. **THE ASK:** one text box: *"write prompt: redraw first image in style of second. every shape and label stays in place; only the style changes. no dotted lines, nothing else drawn. prompt only."*
4. **THE RESULT:** one image box, both pictures wired in, text edge from the ask. Empty prompt.
5. **MANY PICTURES (optional):** the pictures through a Batch into the same sentence. The writer reads one example, not the batch.
6. **LOOK AS WORDS (only if needed):** ask what makes the reference look the way it does, ask for a short prompt, test it, fix it, and paste the final prompt into holders.

## Empty slots
The pictures. The reference. The thing that must not change.

## Watch out
- Mismatched reference: a 3D view as the style for a flat plan fails. Use the same kind.
- Never let the writer name what the reference supplies (colour, material, finish). Say "the look in the second picture".
- Name what must survive: "every house stays in place, same count, none added, none lost."
- If lines must not move at all, add an edge-guided second lane.

## Cost note
One run per picture. Test on one before the folder.
