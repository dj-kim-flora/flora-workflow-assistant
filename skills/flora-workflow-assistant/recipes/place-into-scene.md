# Place into a scene

**Makes:** a product, fixture or design shown inside a real photo of the place it will go: a display in a shop, a sofa in a room, a building on a plot.
**Start with:** the thing as a real file (photo, model screenshot or export) and the real scene photo.
**Shape:** execute. Staged pipeline (ladder: "Staged pipeline").

## Blocks
1. **THE THING:** real file, labelled with its true size ("display, 2.4 m tall").
2. **THE SCENE:** real photo, source in the label.
3. **MATCH THE VIEW:** a view of the thing from the same height, direction and lens as the scene photo. (Skip if the file is already that view.)
4. **MATCH THE LIGHT:** one image box: same shape, same camera as the scene, light read off the scene's shadows, only the surfaces change.
5. **PLACE IT:** one image box. *"the photo stays exactly the same outside the plot. exactly one, no copies. object about 2.4 m tall, shorter than the shop window."*
6. **PEOPLE AND TIME (optional):** one sentence per version ("busy afternoon", "evening, lights on").

## Empty slots
The thing, the scene, the size, the time of day.

## Watch out
- Scale: a real measurement plus something in the frame it is smaller than.
- Never jump from shape to placement. A white block dropped into a photo looks like one.
- Count copies in every batch item.
- A scene that cannot hold the object (a macro close-up for a 2.4 m display) is a bad input. Re-source it.
- A generated scene is a last resort and must be labelled.

## Cost note
Three to five image runs per scene at 2K or 4K. Estimate first.
