# Recipes

A recipe is a short description of a workflow that worked. The assistant reads these at the match step and copies the shape. These starters are written from general patterns, not from any one person's project. Change them, delete them, add your own.

## Where recipes live

Here, in `recipes/`, unless your profile names another place (a folder, a Notion page, a drive). One file per recipe, named like `product-photo-set.md`. Starting a fresh library? Delete the cards you do not need and keep this file.

## The card format

```
# <What it makes>

**Makes:** one line. What comes out and where it goes.
**Start with:** the real files it needs.
**Shape:** explore or execute. Which rung (see ladder-and-recipes.md).

## Blocks
1. <Block name>: input > boxes > output. One line.
2. ...

## Empty slots
What the person fills in.

## Watch out
2 to 4 lines. The failures this recipe has really produced.

## Cost note
Rough cost per run, if known, and what drives it.

## Notes
Where it came from, when it was last checked, who added it.
```

Keep cards short: under 250 words. Describe the shape and the tricks, not a client. Never put a real client name, brand name, file name or project link in a card you share.

## Saving a new one

After a build the person is happy with, the assistant offers: "Want me to save this as a recipe?" It writes the card from the plan and the final canvas, says where it saved it, and asks whether to keep it private. Models go on the card only as jobs ("image edit with references"), not versions, so cards do not go stale.

## Starters in this folder

- `product-photo-set.md`: many views of one product that stay identical
- `batch-variations.md`: 20 versions of one idea from a list
- `brief-to-assets.md`: one writer per deliverable from a brief
- `place-into-scene.md`: a product or object placed into a real photo
- `character-consistency.md`: one person or character across many shots
- `restyle-with-reference.md`: apply a look from one picture to others
- `clip-from-still.md`: a short, locked-camera clip from one image
- `short-film.md`: shots, sound and a cut
- `feature-tour.md`: a canvas that shows every FLORA capability
