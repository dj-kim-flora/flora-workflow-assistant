# Brief to assets

**Makes:** one visual per deliverable named in a written brief: packaging, a logo exploration, a mood board, a poster, a palette.
**Start with:** the brief (PDF or text) and any real logo or product.
**Shape:** execute. One short writer per asset (ladder: "One writer per asset from a brief").

## Blocks
1. **THE BRIEF:** the pages as image boxes (or a document box made by hand). Swapping the brief re-themes everything downstream.
2. **THE ASKS:** one text box per deliverable, each a short ask: *"read attached brief. write image prompt, primary packaging only. prompt only."*
3. **THE PICTURES:** one image box per ask, empty, text edge from its writer.
4. **ONE JUDGE (optional):** a check box over the set, only if the assets must agree.

## Empty slots
The brief. Any real logo or product. Which deliverables to build.

## Watch out
- Name the page ("the packaging section is the second image") when a brief has several pages.
- The whole writer output becomes the prompt. Ask for the prompt only, with no headings.
- A brief that arrives with a real photo or export is no longer this recipe: the file picks the rung.
- Read each writer's output before running its picture.

## Cost note
Five writers plus five images. Writers are cheap; images drive the price.
