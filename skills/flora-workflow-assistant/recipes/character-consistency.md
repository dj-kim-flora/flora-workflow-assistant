# Character consistency

**Makes:** one person or character across many images: a headshot, a full-body shot, 10 outfits or places, several angles, an eye close-up.
**Start with:** a real photo of the person, or a clear description if the character is invented (label it "generated").
**Shape:** explore at the start, then execute with the winner locked as an Element.

## Blocks
1. **THE FACE:** the real photo, or a generated headshot labelled as generated.
2. **THE CHARACTER:** make an Element from the winning headshot by hand in FLORA and name it ("Mara"). From here the prompt says `@[Mara]`.
3. **FULL BODY:** one image box: `@[Mara]` in plain clothes on a plain background. Make an Element from it too.
4. **TEN LOOKS:** one text box with a bulleted list, one short line per outfit or place, into a Batch and one image box with the Elements wired in.
5. **ANGLES:** a technique or a set of image boxes for three angles. Count the faces: one.
6. **CLOSE-UP:** one eye or detail shot to check the identity holds.

## Empty slots
The photo or description. Names for the Elements. The list of looks.

## Watch out
- Elements are made by hand in the UI; tools may not create them.
- Use an Element instead of a long prose lock ("@[model] wearing @[sweater]").
- A mood word anywhere colours the whole frame (`finish-and-checks.md`, "Word leakage"). Add an avoid list: no smiling, no glamour makeup, no jewelry.
- Only a real person's photo with their permission.

## Cost note
Headshot and body are a few runs. The ten-look batch is the main cost.
